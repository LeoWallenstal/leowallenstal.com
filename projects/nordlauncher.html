Hobbyprojekt

Launcher Nordrevived

Jag utvecklade en modern game launcher med Tauri, där HTML och JavaScript användes för frontend och Rust för backend. Launchern skapades för att förenkla installation, uppdatering och start av spelet, som tidigare krävde flera manuella steg. Genom att automatisera uppdateringsprocessen säkerställer launchern även att alla spelare använder rätt version, vilket minskar versionskonflikter med servern och felrapporter av redan åtgärdade buggar.

Varför jag byggde den.

Bakgrund

Nordrevived är ett projekt där man genom reverse engineering av ett gammalt spel har lyckats återuppliva det på nytt. När jag först gick med insåg jag tidigt ett behov av att förenkla installation och uppdatering av spelet. Innan denna launchern fanns var processen för att installera och uppdatera spelet för komplicerad för målgruppen, vilket ledde till frustration bland spelarna. De var först tvungna att ladda ner en zip-fil och extrahera den manuellt och därefter använda olika skriptfiler för att starta spelet beroende på deras operativsystem. De var också tvungna att hålla koll på de senaste uppdateringarna själva och manuellt ladda ner och installera dem på nytt, vilket ofta ledde till att spelare använde fel version av spelet och rapporterade buggar som redan var åtgärdade och i vissa fall att de inte ens kunde starta spelet alls.

Mitt mål

Målet med Nord Launcher var att skapa en mer användarvänlig och effektiv lösning där användarna enkelt kan installera och uppdatera spelet utan att behöva bekanta sig med komplexa processer. Jag ville att användarna skulle kunna ladda ner och installera launchern en gång och sedan därifrån automatiskt få uppdateringar när de är tillgängliga.

Vad jag lärde mig

Jag lärde mig mycket från detta projekt, särskilt när det gäller att skapa användarvänliga gränssnitt och att förstå behovet av enkel installation och uppdatering av programvara. Jag lärde mig även att utveckla och bygga system mot olika operativsystem. Detta projekt ledde mig till att införskaffa enheter med olika operativsystem så som Linux och macOS för att på detta sätt kunna testa och optimera launchern för olika plattformar.

Vad jag skulle göra annorlunda

Om jag började igen skulle jag fokusera mer på att först skapa en minsta viable product (MVP) och sedan iterera på den baserat på feedback från användare istället för att försöka skapa en perfekt lösning direkt.
