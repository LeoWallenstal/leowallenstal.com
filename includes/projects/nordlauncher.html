NordLauncher

En cross-platform launcher utvecklad med Tauri, där HTML och JavaScript användes för frontend och Rust för backend. Syftet med launchern är att förenkla installation, uppdatering och start av spelet NordRevived. Launchern automatiserar tidigare manuella steg och ser till att spelaren alltid använder rätt version.
